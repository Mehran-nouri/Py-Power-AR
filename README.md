### ✨ قابلیت‌ها

- ☝️ **طراحی در هوا** — با انگشت اشاره روی هوا نقاشی بکشید.
- 🤏 **گرفتن آبجکت** — با ژست شست + اشاره، آبجکت‌ها را جابجا کنید.
- 🔄 **چرخش و زوم** — با حرکت Pinch آبجکت‌ها را بچرخانید و بزرگ/کوچک کنید.
- 🌌 **فیزیک واقعی** — گرانش، برخورد، اصطکاک و اینرسی.
- ↩️ **Undo هوشمند** — با ژست مشت تا ۲۰ مرحله به عقب برگردید.
- 🎨 **۵ سبک قلم** — Normal, Marker, Neon, Sketch, Fountain.
- 💾 **ذخیره و خروجی** — پروژه‌ها را ذخیره کنید یا به صورت PNG خروجی بگیرید.

---

### 🎮 کنترل‌ها

| ژست / کلید | عملکرد |
| :--- | :--- |
| ☝️ **یک انگشت** | طراحی روی هوا |
| 🤏 **شست + اشاره** | گرفتن آبجکت |
| ✊ **مشت** | Undo (بازگشت) |
| 🖐️ **دست باز** | لغو عملیات (Cancel) |
| 🤏 **Pinch** | زوم + چرخش |
| ⌨️ **کلید P** | تغییر سبک قلم |
| ⌨️ **کلید G** | روشن/خاموش کردن گرانش |
| ⌨️ **کلید S / L** | ذخیره / بارگذاری پروژه |
| ⌨️ **کلید E** | خروجی PNG |
| ⌨️ **کلید Q / Esc** | خروج از برنامه |
